## Design Specifications

### Color Palette
- Background: #0D1117 → #161B22 (gradient)
- Card glass: rgba(255,255,255,0.05) with 16px blur
- Text primary: #E6EDF3
- Text secondary: #8B949E
- Accent blue: #58A6FF
- Accent purple: #A371F7
- Success: #3FB950
- Warning: #D29922
- Border: rgba(255,255,255,0.1)
- Glow: rgba(88,166,255,0.3)

### Typography
- Monospace: JetBrains Mono
- Sans-serif: Inter or DM Sans

### Components
1. **Glass Card**: Semi-transparent bg, backdrop blur, subtle border
2. **Terminal Block**: Dark glass bg, traffic lights, copy button
3. **Badge System**: OS badges (Linux/macOS/Android), complexity badges
4. **Stats Counter**: Large number with gradient text

### Layout Summary
- **Header**: Sticky glassmorphic nav with logo, key pages, GitHub button
- **Hero**: Gradient title + stats + scrollable showcase carousel
- **Stats Bar**: Horizontal glass strip with clickable metrics
- **Feature Cards**: 3 glass cards highlighting key differentiators
- **Category Grid**: Filterable cards with OS badges and complexity indicators
- **Terminal Blocks**: Glass-effect with traffic lights and copy buttons
- **Footer**: Minimal with GitHub link and license
